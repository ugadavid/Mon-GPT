# Mon GPT<3 0.9.4 — Navigation et informations

**Détaillée** distingue les extraits **Résumé** et **Note**. **Mosaïque** les affiche aussi, avec catégories et tags quand ils existent. Le titre conserve ses deux lignes. Les cartes vides de repères restent sobres ; les textes complets sont dans l’aperçu, l’éditeur et l’infobulle. Normal / Grand garde son sens ; en fenêtre basse, l’image entière se réduit pour laisser les textes accessibles.

Le bandeau renseigne désormais le **projet sélectionné à gauche** : catégories, tags et description si la place le permet. Sélectionner un fil peut changer sa couverture, mais ne remplace pas les informations du dossier. En petite largeur, les pastilles passent sur une ligne compacte sous l’identité. Aucun faux repère dans Tous les fils, À classer ou un projet vide.

**Tous les fils** et **À classer** restent épinglés ; seuls les projets défilent. Les flèches Haut/Bas passent entre les deux parties, avec une seule sélection. Clic droit, tri, branches, Alt+↑/↓ et restauration de session conservent leur fonctionnement. Les cibles de classement restent les projets ; À classer demeure un périmètre virtuel.

Dans un dossier, **Contenu du projet** compte séparément les discussions directement rattachées et les sous-projets immédiats. Recherche et filtres ajustent ce décompte. Les descendants indirects ne sont pas mélangés au contenu direct.

L’éditeur affiche les **Emplacements** juste après l’identité et le lien : résumé « Actuellement dans », puis liste où les rattachements actuels viennent en premier. Ctrl+clic ajoute ou retire une sélection. Les homonymes portent des libellés distincts, sans GUID. **Enregistrer** applique les changements ; ouvrir l’éditeur ne modifie rien. Un projet conserve un seul parent.

**Aide → Gestes et raccourcis** ouvre une fenêtre à rubriques, défilante et accessible au clavier. **Aide → À propos** ouvre une fenêtre indiquant la version et le fonctionnement local. Échap ou Fermer rend le focus à l’application. Le bouton GitHub ouvre explicitement le dépôt.

La fenêtre se redimensionne avec Windows ; les deux tailles de recette ont disparu d’Affichage. La taille et les préférences restent mémorisées dans `interface.json`, hors catalogue métier.

Les gestes validés restent identiques : titre, icône et couverture sélectionnent ; **↗ seul ouvre ChatGPT**. Alt+Entrée active explicitement ↗ du fil focal. Ctrl/Maj sélectionnent un lot ; glisser gauche déplace, glisser droit propose déplacer ou ajouter un rattachement. Ajouter un emplacement ne duplique jamais la fiche.
